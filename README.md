## Счётчик посещений

Считается, **на витрине не показывается**: ни разметки, ни числа, ни подписи ни
на одной из трёх языковых страниц. Числа видны в `versions.html` внутри
`#admin-block`, то есть только после входа Google.

- отсечка двойного счёта — `sessionStorage`: та же вкладка за сессию считается один раз;
- заходы админов (`ADMIN_EMAILS`) не считаются;
- сутки — **UTC**, потому что дату пишет браузер посетителя;
- считаются только заходы, где отработал скрипт: боты и показ из кэша от живого
  читателя не отличаются.

**Посуточная разбивка ждёт правил Firestore.** Замер 03.09.2026: анонимная запись
в `stats/visits/daily/<дата>` отдаёт `403`, правила такой путь не покрывают.
Пока правил нет, в админке вместо чисел стоят прочерки и оранжевая строка, а
общий счёт идёт как шёл. Нужное правило — в
`Y:\CargoLog\Scratch\2026-09-03-sait-blok-A\firestore-rules-daily.txt`.

`weekly.py` (ID ресурса цифрами) — отдельным сообщением от программы.

Cookie-баннера нет и согласия сайт не спрашивает — осознанно: IP анонимизируется,
`allow_google_signals` и `allow_ad_personalization_signals` выключены. Заходы
админа не шлются вовсе: просмотр страницы уходит только после того, как выяснено
состояние входа.
